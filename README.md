# FitLog (공개 배포판)

운동·식단·인바디를 한곳에 기록하는 무료 웹앱입니다. 로그인, 서버, AI 연결이 없고 모든 기록은 사용자 기기의 브라우저 저장소에만 남습니다.

## 들어 있는 기능

- **운동 기록**: `티바로우 30kg 20 40kg 14/14/14/14`, `스쿼트 60kg 10x5`, `축구 90분`처럼 적으면 세트·볼륨·예상 소모 칼로리를 바로 계산하고, 지난번 대비 변화(PR, 증량)와 다음 목표를 보여줍니다.
- **아침 체크인**: 공복 체중, 수면, 컨디션
- **식단 기록**: 음식 이름, 칼로리, 단백질·탄수·지방
- **목표 계산**: 키·체중·나이·활동량으로 하루 목표 칼로리와 영양소 계산 (Mifflin-St Jeor 공식)
- **리포트**: 인바디 결과지형 분석, 지표별 변화 기록, 볼륨·부위별 세트·칼로리 차트, 기록 기반 주간 리포트
- **백업**: JSON 백업·복원, CSV 내보내기, 모든 기록 지우기
- **설치형 앱(PWA)**: 홈 화면에 추가하면 앱처럼 쓰고 오프라인에서도 열립니다

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조와 기본 저장 로직 |
| `app.js` | 운동 해석, 리포트, 체크인, 목표 계산 등 |
| `sw.js` | 오프라인 지원 (네트워크 우선) |
| `manifest.webmanifest`, `icon.png` | 홈 화면 설치용 |
| `meal.jpg` | 식단 화면 배경 사진 |
| `mascot/` | 마스코트 이미지 (`mascot/README.md` 참고) |

## GitHub Pages로 배포하기

1. GitHub에서 **새 저장소**를 만듭니다. 예: `fitlog-app` (Public)
2. **Add file → Upload files**로 이 폴더의 파일을 **폴더 구조 그대로** 올립니다. `mascot` 폴더는 폴더째 끌어다 놓으면 됩니다.
3. 저장소 **Settings → Pages → Branch**를 `main` / `(root)`로 두고 Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

## 수정 후 다시 올릴 때

`app.js`를 고쳤다면 `index.html`의 `app.js?v=1.0.0`과 `sw.js`의 `CACHE`, `SHELL` 안 버전 숫자를 함께 올려 주세요. (예: `1.0.1`)
GitHub Pages는 파일을 최대 10분 캐시하기 때문에, 버전을 올리지 않으면 사용자에게 예전 파일이 보일 수 있습니다.

## 저장 공간

기록은 브라우저 저장소의 `fitlog-public:v1` 한 곳에 저장됩니다. 같은 `github.io` 주소 아래의 다른 앱(예: 개인용 `/fitlog/`)과 저장 공간이 겹치지 않도록 이름을 따로 쓰며, "모든 기록 지우기"와 백업도 `fitlog-public`으로 시작하는 항목만 다룹니다.

## 개인정보

- 서버로 보내는 데이터가 없습니다. 외부 요청은 앱 파일을 불러오는 것뿐입니다.
- 기록은 사용자의 브라우저에만 저장되며, 브라우저 데이터를 지우면 함께 사라집니다.
- 칼로리·목표·리포트는 일반 공식에 따른 추정치이며 의학적 조언이 아닙니다.
