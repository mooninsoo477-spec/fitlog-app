# 마스코트 이미지

홈 화면의 마스코트는 최근 7일 기록으로 계산한 컨디션 단계(1~5)에 따라 바뀝니다.
이 폴더에 아래 이름으로 이미지를 넣으면 자동으로 쓰이고, 파일이 없으면 `default.png`가 대신 보입니다.

| 파일 이름 | 단계 | 어울리는 모습 |
|---|---|---|
| `state-1.png` | 잠깐 재충전 | 지쳐서 앉아 쉬는 모습 |
| `state-2.png` | 몸이 조금 무거워요 | 천천히 걷는 모습 |
| `state-3.png` | 균형을 잡는 중 (기본) | 서서 웃는 모습 |
| `state-4.png` | 기세 좋은 러너 | 달리는 모습 |
| `state-5.png` | 불타는 질주 | 신나게 뛰거나 운동하는 모습 |
| `default.png` | 이미지가 없을 때 | 현재 새싹 캐릭터 |

## 권장 규격

- PNG, **배경 투명**
- 정사각형 **512×512px** 이상 (화면에는 약 145px로 표시)
- 캐릭터가 이미지 가운데 아래쪽에 오도록 여백 조금
- 한 장에 300KB 이하 권장 (첫 화면 로딩 속도)
- 실제 구단·브랜드 로고, 유니폼, 유명 캐릭터가 들어가지 않은 오리지널 이미지
